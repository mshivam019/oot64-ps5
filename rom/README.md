# ROM

Put your own legally dumped Ocarina of Time ROM here as `oot.z64` and run:

```sh
tools/release.sh
```

Supported names: `oot.z64`, `rom.z64`, `oot.n64`, `oot.v64`. You can also pass a
path directly (`tools/release.sh /path/to/oot.z64`) or set `SOH_ROM`.

Nothing in this directory is committed; it is ignored by `.gitignore`.
